# Phase 2 Instruction Runtime 状态

> 更新：2026-08-03

## 已完成

- OpenAI-compatible 私有模型网关，模型地址、名称、密钥和 JSON Mode 均通过环境变量配置；
- Skill 输入与模型输出的 JSON Schema 双向校验；
- `queued → running → succeeded/failed` Run 状态记录；
- 控制台运行、模型名称、Token 用量、耗时和错误码记录；
- 已发布指令型 Skill 部署为 Endpoint；
- Endpoint 独立高熵 API Key、摘要存储、轮换与启停；
- 外部调用与网页调用共用 Run 审计链；
- 每个用户独立的 Skill 会话，可新建、选择、清空和删除，会话固定到具体 Skill 版本；
- 网页运行台采用 Agent 式自然语言对话，展示完整历史消息并支持回车发送；
- 上下文只记录成功运行的输入与输出，默认最多携带最近 10 轮、总计 30000 字符；
- 同一会话采用运行锁避免并发写入导致上下文乱序，不同用户与不同会话互不影响；
- 每个会话拥有用户隔离的托管文件工作区，支持上传、列出、下载、删除和把回复保存为产物；
- TXT、Markdown、CSV、JSON、YAML、HTML、XML、DOCX、XLSX 内容可按上限提取并作为当前会话参考资料；
- 运行控制台、运行记录、Endpoint 管理和模型状态网页；
- 首页三维动态 Skill 立方体与稳定两行标题。

## 安全边界

- API Key 原文只在创建或轮换时返回一次，数据库仅保存 SHA-256 摘要；
- Skill 输入被视为不可信数据，模型系统消息禁止其覆盖 Skill 指令；
- 网页自然语言会话与 Endpoint 严格 JSON Schema 输入分离，外部 API 契约保持不变；
- `code` 类型 Skill 不会在 API 进程中直接执行，只返回沙箱运行时未接入错误；
- 模型密钥不通过平台 API 或网页返回；
- 会话内容只允许所属用户读取和修改，管理员不会自动获得其他用户的对话内容；
- 文件按不可猜测 ID 和用户/会话路径保存，接口逐次校验会话所有权；可执行文件和脚本被拒绝，ZIP/DOCX/XLSX 解包前检查条目数和解压体积；
- 文件内容作为不可信参考资料放入独立提示区，存在总字符上限，不能覆盖 Skill 指令；平台目前不能访问托管目录之外的电脑文件；
- 当前同步执行适合第一版验证，生产并发需要在下一阶段接入任务队列、配额和超时取消。
