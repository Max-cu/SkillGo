# 交付前代码清理（2026-10-22）

本次检查后端函数与导入引用、前端未使用符号，以及接口中的重复实现。
目标是清除已确认的残留，保持现有任务执行行为。

## 已清理

- 删除 `model_config_service.connection_for_model`：仓库内没有调用方；
  当前模型路由仍使用现有的活动连接和模型网关路径。
- 删除 Worker 中仅为旧测试导入而保留的转接符号；测试直接从实际所属模块导入，
  保留原有测试断言。
- 删除产物校验模块中无人引用的旧别名、Agent 循环及接口中的未使用导入。
- 将普通消息和 Skill 任务接口中完全相同的历史附件 ID 解析合并至
  `attachment_requests.parse_existing_file_ids`，保留原来的 422 状态码、提示和去重规则。
- 删除模型设置页中只写不读的 `testResult` 状态及未使用图标。
  连接测试请求、结果提示和耗时展示保持原有行为。
- 开启前端 TypeScript 的 `noUnusedLocals` 和 `noUnusedParameters`，
  使现有构建和 CI 能发现新增的未使用符号。

## 核实后保留

- 快照与恢复：当前默认关闭，但仍有可选启用和历史恢复路径，不能等同于无人使用的代码。
- 旧数据库初始化、模型协议兼容和历史记录读取：仍是兼容现有部署的有效路径。
- 普通对话与同步调用接口：仍注册为公开路由；产品聚焦一次性 Skill 执行，
  并不意味着可以在清理时直接删除现有接口。
- `follow_skill_flow`、上下文观测、自动交付：均有实际运行入口。
- 独立实现但涉及不同记录类型的历史组装，以及不同资源的权限检查：
  没有仅因代码外观相似就合并。
