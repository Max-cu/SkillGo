# 模型超时体系维护记录（2026-09-09）

本文是 v0.3.1 的历史维护记录，不代表当前部署配置。

## 问题与修复

长报告生成持续返回流式数据，却被固定的单轮总预算终止。模型调用层因此区分连接、首响应、流停滞与整体请求预算；单轮总预算允许配置为 0，仍保留首响应及停滞检测。

任务总时限、模型轮数和工具操作数分别配置。数值为 0 的预算表示停用该项限制，不取消重复调用、空闲检测和用户取消机制。

## 诊断与兼容

运行事件保留首响应耗时、数据块数、字节数、重试和错误分类。启用流式传输不改变工具调用及结果的配对要求；取消不能触发新的重试。

配置来源包括环境变量和模型连接设置。排查时应核对服务内生效值，不仅查看配置文件默认值。

## 验证范围

维护时针对长流式生成、首响应等待、流停滞、取消与工具调用恢复运行回归测试。当前实现以代码及现有自动化测试为准；历史测量不能作为所有任务耗时或模型性能的承诺。
